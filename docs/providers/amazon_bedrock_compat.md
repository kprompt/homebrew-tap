# Amazon Bedrock Compatibility Provider

This provider implements the **Amazon Bedrock (compat path)** for the Enterprise Deferred interface.

## Overview

The Amazon Bedrock compat provider allows you to use the Amazon Bedrock API with the existing Enterprise Deferred interface. It supports text generation with parameters such as `max_tokens`, `temperature`, and `top_p`.

## Configuration

To use this provider, you need:

- An endpoint URL for the Amazon Bedrock compat API.
- An API key for authentication.
