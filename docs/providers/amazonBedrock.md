# Amazon Bedrock Provider

This provider enables integration with Amazon Bedrock's generative AI models.

## Configuration

To use the Amazon Bedrock provider, you need:

- **endpoint**: The Amazon Bedrock API endpoint URL (e.g., `https://bedrock.us-east-1.amazonaws.com`)
- **apiKey**: Your API key for authentication
- **modelId**: The Bedrock model identifier you want to use
